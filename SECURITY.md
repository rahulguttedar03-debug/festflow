# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in FestFlow, please report it responsibly by contacting the maintainers directly or opening a private security advisory on GitHub.

Please do not open public issues for sensitive security vulnerabilities. We will respond promptly to investigate and patch any confirmed issues.
